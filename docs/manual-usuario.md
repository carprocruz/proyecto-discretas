# Manual de usuario

1. Ejecuta la aplicación con `npm run dev` y abre la dirección local mostrada por Vite.
2. Explora la sección **Teoría** y abre los apartados desplegables para consultar las definiciones.
3. En **Laboratorio**, añade vértices, conéctalos, muévelos o elimínalos desde la barra de herramientas.
4. Usa **Aleatorio** para generar un grafo de ejemplo o **Limpiar** para comenzar de nuevo.
5. Cambia a **Algoritmos**, selecciona BFS o DFS y define un vértice inicial cuando sea necesario.
6. Ejecuta el algoritmo. Puedes pausar, reanudar, avanzar un paso o reiniciar la animación.
7. Consulta la lista de adyacencia, la matriz, los grados y el número de componentes conexas.
8. En **Retos**, responde el cuestionario y prueba las verificaciones de bipartición y conectividad.

Para una lista de casos esperados, consulta [`verificacion.md`](verificacion.md).
