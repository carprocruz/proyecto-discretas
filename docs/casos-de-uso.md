# Casos de uso

1. Consultar conceptos de teoría de grafos y sus fórmulas.
2. Crear un grafo desde cero en el laboratorio.
3. Generar un grafo aleatorio para realizar pruebas.
4. Agregar, mover, conectar y eliminar vértices y aristas.
5. Cambiar entre grafos dirigidos y no dirigidos.
6. Consultar lista de adyacencia, matriz y grados.
7. Ejecutar y controlar recorridos BFS y DFS.
8. Verificar componentes conexas y bipartición.
9. Resolver el cuestionario y consultar explicaciones.
